Computer Science Quest

Privacy Policy · effective September 17, 2026

The short version

Computer Science Quest collects nothing. There are no accounts, no analytics, no ads, and no network requests of any kind. The handful of settings the app remembers — your lesson progress, your chosen on-screen character, and light/dark appearance — are saved only in local storage on your own device, in a format only this app can read.

Uninstalling the app deletes all of it. Nothing is ever sent anywhere.

1. Who this policy covers

This policy applies to Computer Science Quest (bundle ID com.csquest.app), an iOS app for learning computer science subjects (Process Quest) and block-based coding (Code Quest). It's built and maintained by an individual developer, not a company, and is offered free with no in-app purchases.

2. What the app stores, and where

The app keeps a small amount of state using Apple's standard on-device storage (UserDefaults/SharedPreferences). None of it identifies you personally, and none of it leaves your device:

What is stored locally
Stored valuePurpose
Completed lessons and chaptersRemembers which lessons you've finished, so the path picks up where you left off
Chosen on-screen characterRemembers which avatar (turtle, cat, fox, robot, etc.) you picked for the Code Quest stage
Light/Dark/System appearance choiceRemembers how you like the app to look

That's the complete list. There is no user account, no device identifier, no location data, no camera or microphone access, and no contacts access — the app doesn't request any of those permissions because it doesn't need them.

3. What the app does not do

No analytics SDKs No ad networks No network requests No accounts or sign-in No crash reporting service No cookies

The app's only two dependencies beyond Flutter itself are cupertino_icons (icon glyphs) and shared_preferences (the local storage described above) — both of which run entirely on-device. There is no code in the app that can transmit data anywhere, because it never establishes a network connection in the first place.

4. Children's privacy

Computer Science Quest is rated 4+ and is often used by children. Because the app collects no data of any kind, from anyone, it does not knowingly collect personal information from children under 13, and there is no mechanism by which it could.

5. Changes to this policy

If the app's data practices ever change — for example, if a future version adds an optional feature that requires network access — this page will be updated first, and the version made available through the app's listing will reflect the update before that version ships.
